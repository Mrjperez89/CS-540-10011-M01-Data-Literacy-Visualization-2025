# CS-540-10011-M01-Data-Literacy-Visualization-2025

This repository contains coursework and deliverables for **CS 540 Data Literacy & Visualization** at **Southern New Hampshire University (SNHU)**.  
Artifacts include cleaned datasets, Python-based analyses, visualizations, and written reflections created across course modules.

## Course Goals (What this repo demonstrates)
- Apply **data literacy** concepts to evaluate data quality, reliability, and limitations
- Perform **data preprocessing** (cleaning, reshaping, transforming, blending/merging)
- Create clear **visualizations in Python** to explore patterns and communicate insights
- Develop **data-driven narratives** tailored to stakeholders and decision-making contexts
- Document results in **submission-ready formats** (Word/PDF/HTML exports)

## Repository Structure
> Folder names may vary slightly depending on the export/source, but the layout follows the module sequence.

- `module-1/` — Data cleaning and trust validation (data quality checks, missingness, assumptions)
- `module-2/` — Cleaning and framing data with code; early EDA workflow
- `module-3/` — Preprocessing + blending data (joining/merging, reshaping, feature prep)
- `module-4/` — Comparing visualization approaches for impact (chart choice + communication)
- `module-5/` — Visualizing insights and exploring patterns with Python
- `module-6/` — Advanced visualization techniques (refinement, clarity, readability)
- `module-7/` — Exploratory vs. explanatory analysis; visualization-driven insights
- `module-8/` — Stakeholder storytelling and narrative-driven visualization decisions
- `module-9/` — Course project (integrated datasets + visuals supporting a stakeholder narrative)
- `module-10/` — Final journal reflection (learning growth, challenges, perspective shift)

## Key Deliverables
- **Module Activities & Assignments:** Written submissions (Word) and rendered notebooks (HTML)
- **Module Nine Project:** End-to-end analysis using integrated datasets and visuals to support conclusions
- **Module Ten Journal:** Reflection on challenges, skill application, visualization narrative, and growth

## Tools & Technologies
- **Python:** pandas, matplotlib (and/or Plotly depending on module)

- **HTML Exports:** finalized notebook outputs for grading and review
- **Microsoft Word:** written narrative submissions and reflections
